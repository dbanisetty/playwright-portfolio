# `ai-docs/`

Product context the AI skills read from, kept in the repo so test generation is
reproducible.

- `PRDs/` — one PRD per feature (journeys, acceptance criteria, data needs).
- `scenarios.csv` — the flat scenario list derived from the PRDs: id, feature,
  title, priority, tags, data requirements.

The first PRD (PIM → Add Employee) lands in Phase 2.
